实现方向

让用户看见自己积累的词汇变成一场庆祝。保留 plain / meridian、字号、菜单、引擎和历史库结构；新增与现有按钮一致的 SVG 礼炮按钮，位于历史旁。用户已选定这一交互方向；布局、粒子数量等为代理实现选择，不作为额外用户决定。

状态行为
有历史单词只读查询最近最多 128 个不重复的短词条，随机选取，混合彩纸和 emoji，从两侧发射后自然落下，约 3.6 秒结束。
空历史 / 只有整句播放彩纸和 emoji，不伪造学过的单词。
减少动态效果显示静态词汇庆祝卡片；不做飞行或旋转。
连续点击 / 隐藏 / 缩放 / Escape不堆叠动画或历史读取；重新播放时清理上次效果，隐藏页面、缩放和 Escape 时清理资源。
读取失败仍能放出 emoji，同时显示可读提示；后续点击可重试。

技术与预算

单独的 Canvas 动画模块，最多约 140 个粒子，DPR 上限 2；无新增依赖、无声音、无网络请求、无历史写入。每次点击读取词池，避免删除的历史长期残留。图层不接收指针事件、不抢焦点；按钮支持键盘，独立 live region 提供庆祝反馈。令牌取自当前主题，字体随字号档位。
