    划词翻译

    在任意程序里拖选一段文字，松开鼠标后光标旁会浮出一枚 translate 小图标 （字标 + 一条四段彩虹条），点它就会把这段文字送进本窗口翻译。 原文不会被替换，也不会被修改 —— 译文只出现在这里。

    拖选一段文字松开鼠标后浮出图标
    双击一个词同上，方便查单词
    点图标窗口置顶并翻译选中内容
    右键 / 滚轮 / 点别处收起图标，不做任何事

    普通网页和应用优先通过 Windows UI Automation 直接读取选区。PDF 为避免取词位置偏移，以及其它应用读不到选区时， 会按“剪贴板兜底”设置模拟 Ctrl + C 取词，随后还原剪贴板。 关闭兜底后，PDF 不显示划词图标。 在资源管理器里禁用这条兜底路径，免得选中若干文件时被误触发成「复制文件」。

    关于浏览器的右键菜单：Chrome / Edge 的右键菜单是浏览器自己绘制的， Windows 没有提供任何注册表或 Shell 扩展机制能往里加条目，唯一的正规途径是安装 浏览器扩展。所以这里采用「划词弹图标」的方式；资源管理器的右键菜单则可以注册， 见下节。

    资源管理器右键菜单

    勾选「资源管理器右键菜单」后，在文件或文件夹上点右键会多出一项 翻译（tranSSlater），选中文本文件即可把内容读进本窗口翻译。 支持 UTF-8、UTF-16 与 GBK 编码，超过 512 KB 的文件需要先截取一段。

    这个菜单项写在 HKCU\Software\Classes 下，只影响当前用户、不需要管理员权限； 取消勾选就会整项删除。Windows 11 默认把它折叠进「显示更多选项」，这是系统行为。

    快捷键

    Ctrl + Enter立即翻译，不等自动翻译的停顿
    Esc清空输入框
    Ctrl + H打开翻译历史
    F1打开本说明
    Alt聚焦菜单栏，随后用 ← → 选菜单、↑ ↓ 选项、Enter 执行
    双击菜单栏放大 / 还原窗口

    历史与导出

    翻译记录存在本机 SQLite 数据库里，不设条数上限，也不会自动清理。 工具栏的「历史」按钮或 Ctrl + H 打开抽屉，点任意一条能把完整结果回填到主界面。

    导出从数据库流式读取，不受内存限制，四种格式：

    格式扩展名用途
    CSV 表格.csvExcel 直接打开，带 BOM 不会乱码
    Markdown.md按日期分组，适合当学习笔记
    Anki 导入.txt两列制表符分隔，基本型可直接导入
    JSON 备份.json含完整结果，用于备份或二次处理

    代理与网络

    代理地址只影响 Google 引擎；有道的两个引擎强制直连，不受代理设置影响。 留空时使用系统代理或环境变量里的代理。

    支持 HTTP、HTTPS、SOCKS5、SOCKS5H，地址要写完整，例如 http://127.0.0.1:7890。

    关于

    crafted by renschekhe with love.\heart; open source on https://github.com/fine-structure-constant/tranSSlater

    tranSSlater，基于 Tauri 2、Rust 与 TypeScript 的桌面翻译器。 界面与后端都离线运行，只有翻译请求会发往所选引擎。

    三个引擎用的都是公开的非官方接口，服务可用性和词典字段由上游决定； HTTP 429 会做有限次数的退避重试，其他失败会给出可恢复的错误提示。
